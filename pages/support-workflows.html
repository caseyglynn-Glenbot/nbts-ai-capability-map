Worth knowing

  1. Every call opens a ticket, including resolved calls, connected transfers, hang-ups and voicemails. Filter on no-request to strip the noise.
  2. Transfers don't stop the ticket. The summary records specialist named and transfer result, so a connected call still leaves a trail.
  3. Caller SMS is built but off, pending toll-free SMS verification in Twilio.
  4. Conversation ID in every ticket supports a future reconciliation audit, same pattern as NBTS.
  5. Separate from NBTS. Own KB table, own webhook, own Jira space. Nothing crosses into the NBTS AI Jira project.

Worth knowing

category gap

The 28 categories score clarifier specs

Mechanism type (Tow-Bro, spiral, Riser Bro, Detritor, DAF), bridge, truss, skimmer, scum trough, pier, coatings, civil. None target Defender, Lawson, ETS UV, OSEC or Pacific Ozone, so NBTS product bids score against the wrong rubric.

Fix: add NBTS category sets (filter system, valves and controls, UV dose and NEMA, chemical feed, aquatics code) behind a product picker on the form.
