Rules for every ticket

  1. Same-day first response. Call or email back the same business day, even if the full answer takes longer.
  2. Collect before you troubleshoot: site, contact, product, model and serial, job or PO number, photos.
  3. No warranty promises. Coverage depends on registration, start-up date and contract. Only Customer Experience decides it.
  4. Platinum, Gold and Urgent flags go first. Pool-down and safety issues go to the top of the queue.
  5. Write it down. Put the answer, its source document and any part numbers in the ticket so the next person can reuse it.

Warranty, defects & safety

Hand off
Claims, RMAs, freight damage, failures40 · 7%
Collect
  • Serial number, start-up date, PO / order number
  • Photos and a description of the failure
  • Whether the failed part can be returned
Do this
  1. Do not say whether it is covered.
  2. Send it to Customer Experience using the CX template: customerexperience@xylem.com · 855-267-9201
  3. Keep helping with the technical problem at the same time.
  4. Injury or safety risk (e.g. drain cover cuts): escalate to the lead engineer the same day.
Done when CX has the claim and the customer knows who owns it.

Documents & certificates

Fast answer
Manuals, drawings, specs, submittals, CAD, VGB / NSF 61 / COC25 + 14 · 7%
Do this
  1. Get the exact model number. That is all you need.
  2. Pull certificates from the COC SharePoint. Manuals and specs come from the knowledge base; submittals go through the Submittal Generator.
  3. Custom grates: fill in the grate dimensions and grate information on the certificate. Only the 2008 version is available for these grates.
  4. If no document exists for the model, say so and escalate.
Done when the file is sent and attached to the ticket. Target: same day.

Parts, quotes & orders

Route
Part numbers, pricing, POs, lead time, shipping28 + 18 · 9%
Do this
  1. Identify the part with the Parts Assistant or the product's exploded diagram, using the model / serial.
  2. Give the correct part number, then use the CX template for quote and warranty requests.
  3. Pricing, quotes, PO changes and order status go to CX / inside sales with the SO or PO number.
  4. Platinum-flagged requests go first.
Done when the right part number is in the ticket and sales has it.

Defender operation

Technical
Bump, precoat, air pressure, media, valves, solenoids69 · 13%
Collect
  • Model (SP-xx-xx-xxx), serial, controller (RMF12 / RMF7)
  • Photos of the HMI screen, alarms and gauges
Check in this order
  1. Media and precoat coverage. If spotty, run a Chem Clean Express and check for turbulence.
  2. Air pressure at the regulator on the side of the Defender.
  3. Valves not working: check the solenoid LED and the PLC LED.
Escalate if media is in the pool or the tank must be opened. Use the Defender O&M and the Procedure Guide Generator.
