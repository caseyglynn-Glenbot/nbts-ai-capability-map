Upload the HKOM AS SOLD workbook and get the OSEC L submittal back: Word body, finished PDF with lettered tabs and highlighted data sheets, and a review note that says what to check before release. One upload, no retyping.

HOW TO USE IT

One file. The workbook already holds everything the body needs.

  1. Open the form from the tile below. It opens in a new tab.
  2. Enter your email. The package and review note are sent there.
  3. Upload the HKOM workbook. The <proposal>_AS SOLD.xlsm file in the job's 09 PM/HKOM folder. HKOM Sheet, Firm Scope, Product BOMs and Spec Review are all read from it.
  4. Optional fields. Submittal date (defaults to today), Project Manager name when HKOM carries an employee number, customer name for the cover.
  5. Submit. In about a minute the package is emailed to you and filed to NBTS Jira with the review note.
