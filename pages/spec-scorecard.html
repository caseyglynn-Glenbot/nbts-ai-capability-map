HOW IT WORKS

The process end to end, in plain terms.

StepStageWhat happens
1Bid documents come inA sales engineer uploads the project specs, drawings and addenda and names the project.Needs: the PDFs and a project name. Multiple files at once.
2Every page is readAll pages are transcribed, including drawing sheets, title blocks, schedules and keynotes, not just the written specification. Callouts that only appear on a drawing still count.Produces: the full text of the bid package in one place.
3Technical complexity is scoredThe package is checked against 28 engineering categories covering the mechanism, structure, coatings, corrosion control, civil scope and the specifying consultant.Produces: 28 ratings, each with the specification language that triggered it.
4Commercial position is assessedSeparately, the bid terms are read for margin pressure and execution risk. Open competition and or equal language pull margin down. Guarantees, phasing and custom fabrication pull risk up.Produces: an A, B, C or D position with the reasoning stated.
5Scorecard is assembledTechnical and commercial results combine into one composite result, with the category detail attached underneath.Produces: a single scorecard, filed to Jira and emailed to the submitter.
6The team decidesSales and engineering use the scorecard to decide whether to pursue the bid and how to price it. The system informs the call, it does not make it.Control point: every bid decision stays with the team.

WHY IT MATTERS

What this changes for the business.

  • Better bid selection. Complexity and margin exposure are visible before estimating time goes in.
  • Consistent criteria. Every bid is measured the same way, so results compare across projects and regions.
  • Nothing buried. High cost drivers hidden in drawing callouts get surfaced instead of missed at takeoff.
  • Traceable calls. Each score points back to the specification language behind it, so a bid decision can be defended.
  • A record over time. Scored bids accumulate, showing which project profiles we actually win.
C is the expected default. Competitive language on a public bid drives the position to C, and ambiguous evidence also resolves to C. A page of C results is the scoring working as designed, not a flat model. The strongest position, B, is only assigned when high margin is explicitly supported in the documents.
