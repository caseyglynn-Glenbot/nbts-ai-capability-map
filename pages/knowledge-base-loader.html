WHAT YOU CAN UPLOAD
PDF documents
Manuals, cut sheets, spec sheets, including scanned, image-only files (OCR is applied automatically).
Engineering drawings
P&IDs and technical drawings in PDF, read page-by-page with AI vision, not just text extraction.
Word documents
.docx product write-ups, guides and technical notes.
Excel spreadsheets
.xlsx parts tables and data, flattened to text so the AI can read every row.
Markdown, HTML & text
.md, .html and .txt: notes, exported pages and plain text.
What happens when you upload: the document is read (with OCR for scans and AI vision for drawings), split into short, section-sized chunks, embedded, and stored in the Supabase vector store. Re-uploading the same document replaces the old version, it won't create duplicates. Once processed, the Technical Support AI can cite it when answering customer and field questions.

HOW IT WORKS
What happens after you upload a manual, data sheet or drawing, from the form to an answer on the support line.
You do
1
Open the Knowledge Base Loader

On this page, choose Upload a document for something new or Update a document to replace an older version.

2
Add the file and a little context

The file is required. Product, product source, doc type, revision date and part numbers help the AI file it under the right product.

Automatic
3
The file is read

Each file type takes its own path, then they all rejoin as plain text.

PDFText pulled out; scanned pages get OCR
DrawingAI vision reads each page; page images are saved
WordConverted to PDF, then read
ExcelEvery row turned into text
Markdown, HTML, textRead as is
4
Duplicate check

The text gets a fingerprint and is compared with what is already loaded.

NewContinues to the next step
Changed versionOld copy removed, new one continues
Same as beforeSkipped, nothing changes
5
AI tags it

The AI reads the document and records its brand, product, model variant and type, plus a short summary. Text in other languages is dropped from mixed-language manuals.

6
Split into short sections

The text is cut at headings and paragraphs into sections of about 1,400 characters, roughly a third of a page. Table rows become single lines so each value can be found on its own. Every section is labeled with where it came from.

Source: Defender RMF O&M | Brand: NEPTUNE_BENSON | Product: DEFENDER | Type: manual | Section: 9.1 Troubleshooting

If the effluent valve does not open after precoat, check the output on terminal 33...

7
Indexed for search

Each section is converted into a search fingerprint, so the AI can find it by meaning, not just exact words. Two indexes are built: one for the NBTS phone and text lines, one for the NBTS Jira ticket agent.
