Describe a product in plain English — with a size if you have one — and get the correct NBTS catalog part number back in seconds. Searches the full 3,832-part master list, no SKU memorization required.

What it can do

Search by plain language

3,832 parts

Type what the customer described — "10-inch Dominion butterfly valve," "50 lb sand media" — and it finds the matching catalog part numbers by full-text and fuzzy match.

Grouped by size

exact match

Results come back grouped by size with part number, description and type, so you can see the family at a glance.

Handles valve variants

BS · EA · GO · LO · PA

Many valves exist in several actuation types at one size. It lists the variants — bare stem, electric, gear, lever, pneumatic — instead of guessing which you meant.

Never invents a number

catalog only
